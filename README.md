# PageAgent — 让 AI 替你操作浏览器

> **你只需要说一句话，剩下的它来干。**

一个基于 **DeepSeek** 的跨页面浏览器 Agent（Chrome 扩展）。向它描述目标——搜索整理、填表登录、表格处理、数据抓取、内容总结——它会自己 **观察页面 → 做决策 → 动手操作 → 验证结果**，跨标签、跨页面、跨网站把活干完，再把成品交到你手上。

```
「在百度搜 DeepSeek，打开第一条结果，总结要点」        → 自动开后台搜索页 → 点开结果 → 通读正文 → 输出总结
「把在线表格的 B2:D8 填上示例数据，校验一遍」          → 识别单元格 → 按格号定位 → 双击编辑 → 填完读回验证
「把刚才的总结存成文件」                                → 一键下载 md 文件
「这个网站怎么操作，我演示一遍给你看」                  → 你操作一遍，它学会，下次同类操作直接照做
```

**和普通爬虫 / 脚本最本质的区别：它读的是浏览器真实渲染出来的页面，不是服务端源码。** React/Vue 动态页面、CSS-module 随机类名、连内容画在 canvas 上的在线表格 / 在线文档，它都读得懂、操作得了、还会回头验证结果。

> `v0.1.0` · Chrome 111+ · 基于 DeepSeek V4 · 纯前端、无构建、无依赖，加载即用

## 它为什么值得一试

### 1. 看得懂真实网页，不止是「读 HTML」

很多自动化工具读的是服务端返回的源码，遇到动态渲染就抓瞎。PageAgent 直接读**浏览器当前渲染出来的活 DOM**：

- CSS-module 随机哈希类名、动态插入的元素，全部照读不误；
- 没有 `role`/`onclick` 的「手型 div/span 按钮」——靠扫描样式表里 `cursor:pointer` 的手型选择器一样识别得出、点得到；
- 每次决策都重新扫描页面，快照里给出的「可交互元素 + 正文摘要」，就是大模型能看懂、能下手的一整页。

### 2. 内容画在 canvas 上？照样读得懂、点得到

在线表格、在线文档这类「把内容画在画布上」的应用，DOM 里根本没有文字——多数 Agent 直接放弃。PageAgent 在页面绘制前注入钩子，拦截 `fillText/strokeText`，把画上去的每个字连同坐标都记下来：

- 快照能给出**画布文字 + 准确坐标**，还能按视口坐标点选画布目标位置；
- 钩子对页面绘制零干扰，未启用时几乎零开销。

### 3. 会用在线表格：识别格号、双击编辑、读回验证

遇到 Excel / Google Sheets / 腾讯文档 / WPS 这类在线表格：

- 识别「单元格名称框」，按格号直接跳格——`D2`、`$A$1`、`E5:G8` 都行；
- `F2` 进入编辑、**双击就地编辑**（单击只是选中），填完自动读回验证写对了没有；
- 按**通用格式**识别、不针对任何具体站点，换个表格站一样能用。

### 4. 真·跨页面执行，前台后台两种模式

Agent 自己开标签、自己编排，执行模式可在设置里切换：

- **前台执行（默认）**：Agent 打开/切换操作标签时浏览器把它切到前台，你能**实时看着它操作**；
- **后台执行（设置里勾选）**：自开标签后台打开、不抢焦点，你在前台该干嘛干嘛；
- 自动归入「PageAgent N」标签分组统一管理，任务结束**一键清空**，不留垃圾标签；
- **批量跨页一气呵成**：要"读 20 条再总结"这类任务，它一批新开多个详情页并行加载、逐个读取，批末一次性把所有内容汇总给你，不用逐条点开-返回；
- 跨页任务自动等待新页就绪再继续，对话上下文跨标签保留。

### 5. 越用越聪明：会演示、会复盘、会收藏

- **教我模式**：说一句「我教你 / 你看我怎么操作」，它实时记录你在页面上的每一步点击 / 输入 / 下拉 / 回车，先复述给你确认、再照做——过程只教学、不沉淀经验（经验统一由复盘沉淀）；
- **经验库自动沉淀**：复盘时把本轮的实际操作轨迹发给大模型，判断哪些操作**未来值得复用**——绕弯纠正后的正确做法、以及一路顺利但通用（下次还会再做）的操作都算，每条经验 = **场景简述 + 参数声明 + 可执行 JS**：大模型把「怎么做才对且省事」实现成可运行的代码，依赖任务具体值的地方声明成参数（代码里用 `args.<参数名>` 取）；之后 Agent 在同站遇到相符场景就用 `exec_code` 调用这段代码并传参数一步完成，不再一步步重跑；明显一次性、纯阅读无交互的站点不沉淀——操作过的网站越多它越「懂行」，但宁缺毋滥；
- **书签复盘**：任务结束后自动把访问过的有用网站筛出来写进书签，标题带「作用 + 使用技巧」，书签索引越用越丰富，下次一句「打开我的网盘」它直接凭标题开站——点名某站时按索引里的网址**原样打开**、不凭印象猜域名。

### 6. 像真人一样操作，降低被风控误判

逐字输入（15–45ms/字）、点击随机停顿（0.5–2s）、动作间随机等待，模拟真人浏览节奏。同时内建**三档无进展自检**，绝不傻等、绝不原地打转：

- **连续动作级**：连续失败 / 重复执行同一动作 / 空等累计到阈值，就主动请使用者手把手演示；
- **同一目标级**：同一个（动作 + 结果）反复出现、页面却没变化（典型如 ref 漂移后反复点到同一个错误元素）——3 次提醒换招、6 次升级手把手演示；
- **轮级**：每轮都在动手改页面、动作还全部成功，但页面状态和步骤计划纹丝不动——3 轮提醒换招、6 轮硬停转教我，不空转到天荒地老。

### 7. 多会话并发，5 个 Agent 同时干活

最多 5 个互不干扰的会话并行：各自独立的消息列表、独立的标签分组、独立的运行状态，点顶部会话栏随时切换。关掉一个会话的标签页，不影响其他会话继续跑。

### 8. 长上下文 + 自动压缩，聊一整场都记得

默认装下 DeepSeek V4 的 **1M token** 上下文，历史从最新往前装到放不下为止；用到 70% 阈值时自动把中间历史压缩成「已完成进展 / 踩过的坑 / 注意点」摘要，长任务可持续很多轮不断线。

**上下文按板块分策略管理，不搞一刀切硬截断**：
- 系统提示词、原始目标、最新指令——**无损**，永远完整呈现；
- 工具结果——最近 `RESULT_KEEP_ROUNDS`（5）个回合**全量**保留，更早的回合降级为短空壳（保留开头摘要，占极小上下文）；写历史不再做"一律 3000 字符"的截断，只有 30000 字符/条的存储软上限兜底；
- 模型自己的输出——无损记录，只在压缩时并入摘要。

配套地，读类工具提供**按需取参**，让模型自己决定要多少数据，而不是被工具层硬截：
- `read`：`selector`（直接读指定元素下的内容，不必先拿 ref）+ `limit`（只要开头 N 字符）；
- `readCss`：`props`（只要几个计算属性，省略=全量）；
- `pageInfo`：`field` + `html`（字段子集，省略=全量元信息）；
- `getJsErrors`：`limit`（只要最近几条）。

### 9. 卡住会求助，绝不闷头瞎撞

遇到验证码、登录墙、人机验证：请你**在页面上手动操作**（自动把相关标签切到前台），完成后点一下「继续」它接着做；需要账号、手机号等信息的直接在对话里回复；反复失败 / 重复动作 / 同目标反复点击 / 多轮空转累计到阈值时，它会先**提醒换招**、再主动请你**手把手演示**（硬停），并把学到的沉淀下来——而不是无限重试浪费你的时间。**点错元素也瞒不过它**：动作结果与实际点到的东西对不上（ref 漂移，如想点「全选」却点成了「邮箱」）时，它当场识别并警示"别按旧 ref 继续点"，改按页面实际出现的文字重来。求助卡会讲清「当前卡在哪一步 + 失败原因（能说的）」，并明确请你做什么（页面上操作完点继续，或在对话里告诉它该怎么做），不会只甩一句"连续操作失败"让你自己猜——"当前步骤"取的是步骤计划里第一个未完成的步骤，比整句大目标具体。

### 10. 接到指令先拆解成步骤，实时划线给你看

下一条指令，它会先把达成目标要做的事拆成 3~8 步步骤清单，悬浮展示在状态栏下方；每完成一步就**划掉一线**，整场进度一目了然。已经划掉的线**不会因它重新汇报计划而被撤销**——重发的计划按文字与旧计划合并、保留完成状态，只有真实推进才继续划线。任务做完后清单保留、全部划线，直到你下一条新指令才开始新的拆解。面板中途重载也不丢：步骤计划与最近的动作轨迹都会从后台恢复。

## 快速开始

1. 打开 `chrome://extensions`，右上角打开 **开发者模式**；
2. 点击 **加载已解压的扩展程序**，选择本项目目录；
3. 点击工具栏的扩展图标，打开 **PageAgent** 侧边栏；
4. 在侧边栏点 **设置**，填入 DeepSeek API Key 与模型，即可开始。

## 使用要点

- **@MAIN**：首条指令所在的标签被固定为该会话的主页面；后续指令继续在 @MAIN 和你纳入的标签上工作。要换页面工作，点顶部会话栏 **＋ 新建** 开新会话，或直接让 Agent `open_tab` / `use_tab`。
- **顶部会话栏**：一排「会话 N」胶囊，圆点颜色表示状态（灰=空闲、蓝=运行中、橙=需你手动操作、绿=等待确认）。点胶囊切换会话，点 **×** 删除、末尾 **＋ 新建**（最多 5 个）。
- **运行中打断**：直接发新指令会打断当前操作并重新理解——可能是纠正你的做法，也可能是改变目标；它不会一收到就盲目放弃原始目标。
- **停止 vs 清空**：「■ 停止」只是停下当前任务，对话保留可继续；「清空本会话」关掉本会话自开标签并清空记录，会话保留。
- **登录态**：需要登录的站点，Agent 直接在当前已登录的浏览器会话中操作，不需要额外凭证。

## 工作原理

```
panel.html/js/css  侧边栏 UI（顶部会话栏、聊天消息流、设置、发送 / 停止 / 清空）
       │  chrome.runtime 消息
background.js      Service Worker：Agent 循环（多会话）+ DeepSeek 调用 + 状态持久化
       │  tabs.sendMessage / tabs.update / scripting 注入
content.js         页面快照（可交互元素 + 正文摘要）+ 动作执行（click/type/上传/富文本/…）
canvas-hook.js     画布文字钩子（document_start + MAIN world，拦截 fillText/strokeText）
picker.html/js     uploadFile 本地文件选择弹窗（选文件 → base64 回传 background）
```

**Agent 循环**：`GET_SNAPSHOT`（当前操作标签）→ 拼接快照消息（标签列表 + 书签索引 + 当前任务步骤计划 + 原始目标 + 本站操作经验 + 尾部历史；上下文达阈值先自动压缩）。本站操作经验每条带编号 `[经验N]`、注明可执行与否与参数说明——Agent 遇相符场景用 `{"action":"exec_code","idx":N,"args":{参数名:值}}` 直接执行其代码传参一步完成，不抄写代码→ 调 DeepSeek（`response_format: json_object`）→ 解析 `{actions, steps}`（动作 + 每轮随带的步骤计划）→ 执行 → 重复。`finish` 或失败后回到 `idle` 等待下一条指令，**不结束对话**；`maxSteps` 按每轮指令重置。步骤计划用 `mergePlan` **按文字合并**而非整表替换：模型重发时文本小漂移 / 漏标 `done` 都不会撤销已划线的步骤，新增步骤追尾、上限 12 步，连续省略 steps 时轻提醒补报。每轮按「页面指纹 + 计划未完成步数」判定是否推进，配合同目标重复检测（`REPEAT_ACTION_LIMIT=3` 提醒换招 / `REPEAT_TEACH_LIMIT=6` 硬停）与轮级无进展检测（`UNPROD_REMIND_LIMIT=3` 提醒 / `UNPROD_TEACH_LIMIT=6` 硬停转教我），再叠加 ref 漂移警示（结果 label 与实际点到的对不上就点破"别按旧 ref 继续点"）——发现空转先提醒换招、到阈值转教我，不无限重试。

**多标签编排**：`@MAIN`（你的标签，不入分组）→ `@T1/@T2/...`（Agent 自开标签，`chrome.tabs.group` 归入本会话「PageAgent N」分组，任务结束删组一键清空）→ `@U1/@U2/...`（你已有的标签，`use_tab` 纳入任务）。自开/切换标签的显隐由设置 `backgroundExec` 控制：后台执行 `active:false` 不抢焦点，前台执行（默认）`active:true` 切到浏览器前台；每轮结束只清理本会话分组，你的 @MAIN/@U 永不自动关闭。

**跨页恢复**：跨页动作（`open_tab` / `search` / `navigate` / 点击新开页）**操作后一律不等待**——多个新页并行加载，页面就绪统一由**下一个**读取/操作动作执行前自动等（读快照前 `ensureCurrentOpReady`，上限 10s，超时按动作失败走原有自愈）。任务状态持久化到 `chrome.storage.session`，应对 MV3 service worker 被回收。**批内跨页**：`open_tab`/`navigate`/`switch_tab` 等不再打断整批，连续跨页之间不等，系统在真正读取/点击页面的动作前自动等当前操作标签就绪。

**复盘**：`finish` 时并行做两件事——① 书签复盘：把本轮实际访问过的网站筛出有用的写入书签（新站收藏 / 已收藏合并改进标题，一律存网站根 URL）；② 经验复盘：统计各站点的动作数 / 失败数 / 可交互操作数，对「动作 ≥3 或失败 ≥2 或做过可交互操作」的候选站点，把本轮实际操作轨迹（如 `open_tab→click(邮箱)→click(全选)→scroll→click(全选)`）交给大模型判断哪些操作**未来值得复用**——绕弯纠正后的正确做法、一路顺利但通用（下次还会再做）的操作都算——有复用价值才沉淀，每条 = **场景简述 + 参数声明 + 可执行 JS**——大模型把「怎么做才对且省事」实现成可执行的代码、依赖任务具体值处声明成参数（代码里用 `args.<参数名>` 取），与既有经验冲突自动合并；之后同站相符场景 Agent 用 `exec_code` 传参一步完成；明显一次性 / 纯阅读无交互的站点不沉淀。经验只沉淀**真做成**的轮次——最终结果自认未完成 / 需重做的（`selfReportedFailure` 自检）整轮跳过，避免把 ref 漂移的无效点击这类错误路径当"成功经验"写进经验库跨会话传染。

**动作集**：标签 `open_tab` / `search` / `switch_tab` / `list_tabs` / `use_tab` / `close_tab`；页面 `click` / `clickText` / `clickSelector` / `clickAt` / `dblclickAt` / `hover` / `show` / `hide` / `type` / `select` / `scroll` / `snapshot`（`offset` 翻下一批元素窗口）/ `read`（`selector` / `limit` 按需取段）/ `wait` / `keypress` / `navigate` / `gotoCell` / `uploadFile`（base64 / 文本自动编码 / 本地文件弹窗）/ `pasteRich`（富文本 HTML 粘贴）/ `readCss`（`props` 按需取属性，省略=全量计算样式）/ `pageInfo`（url / 标题 / iframe 清单，field 过滤）/ `getJsErrors` / `clearJsErrors`（跨窗口 JS 错误采集）；结果 `save_file`；书签 `bookmarks_read` / `bookmarks_write` / `bookmark_find`；求助 `ask_user`（`page` / `reply` / `teach` / `confirm`）；消息 `say`；结束 `finish`。

> Agent 会**先判题**：当前页与任务无关时（如「搜索 DeepSeek 资讯并总结」），不会在当前页瞎操作，而是用 `search` 后台开搜索页或 `open_tab` 直接开站；只有任务确实发生在当前页时才在当前页操作。

## 面向开发者

**技术要点**

- **MV3 架构**：Service Worker 跑 Agent 循环 + 多会话状态管理；`chrome.storage.session` 持久化应对 worker 回收；心跳 alarm 检测加载超时（120s）与循环停滞自愈。
- **画布钩子**：`canvas-hook.js` 以 `world:"MAIN"` + `document_start` 注入页面自身环境，赶在任何页面脚本绘制前包一层 `fillText/strokeText`；坐标经当前 2D 变换换算成 canvas 设备坐标，去重 + 批量回传（120ms 节流），记录逻辑全 `try/catch`，原函数永远原样调用。未 armed 时零开销。
- **元素定位**：优先用快照时的 live 元素引用（`ref`→元素），元素被重渲染替换后才回退 CSS 选择器（id/testid/位置，**不用 class**——动态 app 类名常带随机后缀不稳定）。
- **表格通用识别**：按「格子号格式」（`D2` / `$A$1` / `E5:G8`）识别单元格名称框，不针对具体站点；`gotoCell` 输格号 + 回车 + 读回验证，`dblclickAt` 双击唤起就地编辑。
- **非侵入运行**：设置「后台执行」时自开标签 `active:false` 不抢焦点、`tabGroups` 分组管理、任务结束删组清理；`window.open` 新开的页面后台兜底把焦点还给用户。默认「前台执行」则 Agent 打开/切换的操作标签切到浏览器前台，实时可见。

**文件说明**

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、side panel、content script 注入 |
| `background.js` | Agent 循环（多会话）、LLM 调用、会话状态、跨页恢复、广播 |
| `content.js` | 页面快照生成、动作执行（含 JS 错误采集）、AGENT_READY 上报 |
| `canvas-hook.js` | 画布文字钩子（拦截绘制、回传文字与坐标） |
| `picker.html/js` | uploadFile 本地文件选择弹窗（base64 回传，长连接保活） |
| `panel.html/css/js` | 侧边栏 UI |

**开发调试**

- 语法检查：`python3 -m json.tool manifest.json && for f in background.js content.js panel.js picker.js; do node --check $f; done`
- 改动 content script 后需在 `chrome://extensions` 点击扩展的 **刷新** 按钮重新加载。
- 查看 background 日志：`chrome://extensions` → 该扩展 → "Service Worker" 链接 → DevTools Console。

## 已知限制

- **后台标签可能被 Chrome 丢弃**：内存压力下 Chrome 可能 discard 后台标签，任务会等待直至超时。长任务建议关掉不用的标签。
- **受限页面**：content script 无法注入 `chrome://`、Chrome 商店等受限页面。Agent 检测到会自动跳过（直接另开任务相关网页），不会反复失败空转。
- **上下文成本**：每步携带快照，输入为 system + 书签索引 + 压缩摘要 + 原始目标 + 尾部历史；长前缀命中 DeepSeek 自动前缀缓存，每步只付增量。超大页面靠 `read` 按需取全文。
- **LLM 限流 / 费用**：需要有效 Key，注意账户余额与频率限制。
- **标签清理边界**：若你手动把自己的标签拖进 PageAgent 分组，删除分组时会一并关闭——所以请不要把个人标签放进该组。
