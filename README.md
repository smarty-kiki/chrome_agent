# PageAgent — 让 AI 替你操作浏览器

> **你只需要说一句话，剩下的它来干。**

一个基于 **DeepSeek** 的跨页面浏览器 Agent（Chrome 扩展）。向它描述目标——搜索整理、填表登录、表格处理、数据抓取、内容总结——它会自己 **观察页面 → 做决策 → 动手操作 → 验证结果**，跨标签、跨页面、跨网站把活干完，再把成品交到你手上。

```
「在百度搜 DeepSeek，打开第一条结果，总结要点」        → 自动开后台搜索页 → 点开结果 → 通读正文 → 输出总结
「把在线表格的 B2:D8 填上示例数据，校验一遍」          → 识别单元格 → 按格号定位 → 双击编辑 → 填完读回验证
「把刚才的总结存成文件」                                → 一键下载 md 文件
「这个网站怎么操作，我演示一遍给你看」                  → 你操作一遍，它学会，下次同类操作直接照做
```

**和普通爬虫 / 脚本最本质的区别：它读的是浏览器真实渲染出来的页面，不是服务端源码。** React/Vue 动态页面、CSS-module 随机类名、连内容画在 canvas 上的在线表格 / 在线文档，它都读得懂、操作得了、还会回头验证结果。

> `v0.1.0` · Chrome 111+ · 基于 DeepSeek V4 · 纯前端、无构建、无依赖，加载即用

## 它为什么值得一试

### 1. 看得懂真实网页，不止是「读 HTML」

很多自动化工具读的是服务端返回的源码，遇到动态渲染就抓瞎。PageAgent 直接读**浏览器当前渲染出来的活 DOM**：

- CSS-module 随机哈希类名、动态插入的元素，全部照读不误；
- 没有 `role`/`onclick` 的「手型 div/span 按钮」——靠扫描样式表里 `cursor:pointer` 的手型选择器一样识别得出、点得到；
- 每次决策都重新扫描页面，快照里给出的「可交互元素 + 正文摘要」，就是大模型能看懂、能下手的一整页。

### 2. 内容画在 canvas 上？照样读得懂、点得到

在线表格、在线文档这类「把内容画在画布上」的应用，DOM 里根本没有文字——多数 Agent 直接放弃。PageAgent 在页面绘制前注入钩子，拦截 `fillText/strokeText`，把画上去的每个字连同坐标都记下来：

- 快照能给出**画布文字 + 准确坐标**，还能按视口坐标点选画布目标位置；
- 钩子对页面绘制零干扰，未启用时几乎零开销。

### 3. 会用在线表格：识别格号、双击编辑、读回验证

遇到 Excel / Google Sheets / 腾讯文档 / WPS 这类在线表格：

- 识别「单元格名称框」，按格号直接跳格——`D2`、`$A$1`、`E5:G8` 都行；
- `F2` 进入编辑、**双击就地编辑**（单击只是选中），填完自动读回验证写对了没有；
- 按**通用格式**识别、不针对任何具体站点，换个表格站一样能用。

### 4. 真·跨页面执行，全程不打扰你

Agent 自己开后台标签、自己编排：

- 自开标签**后台打开、不抢焦点**，你在前台该干嘛干嘛；
- 自动归入「PageAgent N」标签分组统一管理，任务结束**一键清空**，不留垃圾标签；
- 跨页任务自动等待新页就绪再继续，对话上下文跨标签保留。

### 5. 越用越聪明：会演示、会复盘、会收藏

- **教我模式**：说一句「我教你 / 你看我怎么操作」，它实时记录你在页面上的每一步点击 / 输入 / 下拉 / 回车，先复述给你确认、再照做——并把这套流程**沉淀成该网站的「操作技巧」**，下次同类操作自动加载复用（技巧只记动作流程，不存你输入的账号密码等具体值）；
- **技巧库自动沉淀**：它自己碰壁绕弯路的操作，复盘时自动总结成技巧；操作过的网站越多，它越「懂行」；
- **书签复盘**：任务结束后自动把访问过的有用网站筛出来写进书签，标题带「作用 + 使用技巧」，书签索引越用越丰富，下次一句「打开我的网盘」它直接凭标题开站，不用瞎搜。

### 6. 像真人一样操作，降低被风控误判

逐字输入（15–45ms/字）、点击随机停顿（0.5–2s）、动作间随机等待，模拟真人浏览节奏。同时会识别「空转」——连续无进展的等待自动停止，不会傻等浪费时间。

### 7. 多会话并发，5 个 Agent 同时干活

最多 5 个互不干扰的会话并行：各自独立的消息列表、独立的标签分组、独立的运行状态，点顶部会话栏随时切换。关掉一个会话的标签页，不影响其他会话继续跑。

### 8. 长上下文 + 自动压缩，聊一整场都记得

默认装下 DeepSeek V4 的 **1M token** 上下文，历史从最新往前装到放不下为止；用到 70% 阈值时自动把中间历史压缩成「已完成进展 / 踩过的坑 / 注意点」摘要，长任务可持续很多轮不断线。

### 9. 卡住会求助，绝不闷头瞎撞

遇到验证码、登录墙、人机验证：请你**在页面上手动操作**（自动把相关标签切到前台），完成后点一下「继续」它接着做；需要账号、手机号等信息的直接在对话里回复；反复失败原地打转时，它会主动请你**手把手演示**，并把学到的沉淀下来——而不是反复重试浪费你的时间。

## 快速开始

1. 打开 `chrome://extensions`，右上角打开 **开发者模式**；
2. 点击 **加载已解压的扩展程序**，选择本项目目录；
3. 点击工具栏的扩展图标，打开 **PageAgent** 侧边栏；
4. 在侧边栏点 **设置**，填入 DeepSeek API Key 与模型，即可开始。

## 配置

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| API Key | DeepSeek API Key（[申请](https://platform.deepseek.com)） | 空 |
| Base URL | OpenAI 兼容接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-v4-flash`（V4 Flash，推荐）或 `deepseek-v4-pro` | `deepseek-v4-flash` |
| 温度 | 0–2 | 0.2 |
| 最大步数 | Agent 最多执行的决策步数 | 25 |
| 上下文窗口 | 按 token 估算的输入上下文上限 | 1000000（DeepSeek V4 为 1M） |
| 压缩阈值 | 上下文使用到该比例时自动压缩历史 | 70 |
| 搜索模板 | 任务与当前页无关时，Agent 用它开搜索页 | `https://www.bing.com/search?q=` |

> 注：`deepseek-chat` / `deepseek-reasoner` 是 V3/R1 时代的旧别名，已于 2026-07-24 退役，请用 V4 新 ID。

## 使用要点

- **@MAIN**：首条指令所在的标签被固定为该会话的主页面；后续指令继续在 @MAIN 和你纳入的标签上工作。要换页面工作，点顶部会话栏 **＋ 新建** 开新会话，或直接让 Agent `open_tab` / `use_tab`。
- **顶部会话栏**：一排「会话 N」胶囊，圆点颜色表示状态（灰=空闲、蓝=运行中、橙=需你手动操作、绿=等待确认）。点胶囊切换会话，点 **×** 删除、末尾 **＋ 新建**（最多 5 个）。
- **运行中打断**：直接发新指令会打断当前操作并重新理解——可能是纠正你的做法，也可能是改变目标；它不会一收到就盲目放弃原始目标。
- **停止 vs 清空**：「■ 停止」只是停下当前任务，对话保留可继续；「清空本会话」关掉本会话自开标签并清空记录，会话保留。
- **登录态**：需要登录的站点，Agent 直接在当前已登录的浏览器会话中操作，不需要额外凭证。

## 工作原理

```
panel.html/js/css  侧边栏 UI（顶部会话栏、聊天消息流、设置、发送 / 停止 / 清空）
       │  chrome.runtime 消息
background.js      Service Worker：Agent 循环（多会话）+ DeepSeek 调用 + 状态持久化
       │  tabs.sendMessage / tabs.update / scripting 注入
content.js         页面快照（可交互元素 + 正文摘要）+ 动作执行（click/type/…）
canvas-hook.js     画布文字钩子（document_start + MAIN world，拦截 fillText/strokeText）
```

**Agent 循环**：`GET_SNAPSHOT`（当前操作标签）→ 拼接快照消息（标签列表 + 书签索引 + 原始目标 + 本站操作技巧 + 尾部历史；上下文达阈值先自动压缩）→ 调 DeepSeek（`response_format: json_object`）→ 解析动作 → 执行 → 重复。`finish` 或失败后回到 `idle` 等待下一条指令，**不结束对话**；`maxSteps` 按每轮指令重置。

**多标签编排**：`@MAIN`（你的标签，不入分组）→ `@T1/@T2/...`（Agent 后台自开标签，`chrome.tabs.group` 归入本会话「PageAgent N」分组，任务结束删组一键清空）→ `@U1/@U2/...`（你已有的标签，`use_tab` 纳入任务）。自开标签一律 `active:false` 不抢焦点；每轮结束只清理本会话分组，你的 @MAIN/@U 永不自动关闭。

**跨页恢复**：`open_tab` / `navigate` 后任务置为 `awaiting_nav`，新页 content script 就绪后广播 `AGENT_READY` 恢复循环；任务状态持久化到 `chrome.storage.session`，应对 MV3 service worker 被回收。

**复盘**：`finish` 时并行做两件事——① 书签复盘：把本轮实际访问过的网站筛出有用的写入书签（新站收藏 / 已收藏合并改进标题，一律存网站根 URL）；② 技巧复盘：统计各站点的动作数 / 失败数，对「反复失败 ≥2 次或绕弯 ≥4 次」的站点总结成技巧，与既有技巧冲突去重合并后存储。

**动作集**：标签 `open_tab` / `search` / `switch_tab` / `list_tabs` / `use_tab` / `close_tab`；页面 `click` / `hover` / `type` / `select` / `scroll` / `read` / `wait` / `keypress` / `navigate` / `dblclickAt` / `gotoCell`；结果 `save_file`；书签 `bookmarks_read` / `bookmarks_write` / `bookmark_find`；求助 `ask_user`（`page` / `reply` / `teach` / `confirm`）；消息 `say`；结束 `finish`。

> Agent 会**先判题**：当前页与任务无关时（如「搜索 DeepSeek 资讯并总结」），不会在当前页瞎操作，而是用 `search` 后台开搜索页或 `open_tab` 直接开站；只有任务确实发生在当前页时才在当前页操作。

## 面向开发者

**技术要点**

- **MV3 架构**：Service Worker 跑 Agent 循环 + 多会话状态管理；`chrome.storage.session` 持久化应对 worker 回收；心跳 alarm 检测加载超时（120s）与循环停滞自愈。
- **画布钩子**：`canvas-hook.js` 以 `world:"MAIN"` + `document_start` 注入页面自身环境，赶在任何页面脚本绘制前包一层 `fillText/strokeText`；坐标经当前 2D 变换换算成 canvas 设备坐标，去重 + 批量回传（120ms 节流），记录逻辑全 `try/catch`，原函数永远原样调用。未 armed 时零开销。
- **元素定位**：优先用快照时的 live 元素引用（`ref`→元素），元素被重渲染替换后才回退 CSS 选择器（id/testid/位置，**不用 class**——动态 app 类名常带随机后缀不稳定）。
- **表格通用识别**：按「格子号格式」（`D2` / `$A$1` / `E5:G8`）识别单元格名称框，不针对具体站点；`gotoCell` 输格号 + 回车 + 读回验证，`dblclickAt` 双击唤起就地编辑。
- **非侵入运行**：自开标签 `active:false` 不抢焦点、`tabGroups` 分组管理、任务结束删组清理；`window.open` 新开的页面后台兜底把焦点还给用户。

**文件说明**

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、side panel、content script 注入 |
| `background.js` | Agent 循环（多会话）、LLM 调用、会话状态、跨页恢复、广播 |
| `content.js` | 页面快照生成、动作执行、AGENT_READY 上报 |
| `canvas-hook.js` | 画布文字钩子（拦截绘制、回传文字与坐标） |
| `panel.html/css/js` | 侧边栏 UI |

**开发调试**

- 语法检查：`python3 -m json.tool manifest.json && for f in background.js content.js panel.js; do node --check $f; done`
- 改动 content script 后需在 `chrome://extensions` 点击扩展的 **刷新** 按钮重新加载。
- 查看 background 日志：`chrome://extensions` → 该扩展 → "Service Worker" 链接 → DevTools Console。

## 已知限制

- **后台标签可能被 Chrome 丢弃**：内存压力下 Chrome 可能 discard 后台标签，任务会等待直至超时。长任务建议关掉不用的标签。
- **受限页面**：content script 无法注入 `chrome://`、Chrome 商店等受限页面。Agent 检测到会自动跳过（直接另开任务相关网页），不会反复失败空转。
- **上下文成本**：每步携带快照，输入为 system + 书签索引 + 压缩摘要 + 原始目标 + 尾部历史；长前缀命中 DeepSeek 自动前缀缓存，每步只付增量。超大页面靠 `read` 按需取全文。
- **LLM 限流 / 费用**：需要有效 Key，注意账户余额与频率限制。
- **标签清理边界**：若你手动把自己的标签拖进 PageAgent 分组，删除分组时会一并关闭——所以请不要把个人标签放进该组。
