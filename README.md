# PageAgent — 跨页面 AI 浏览器助手（Chrome 扩展）

一个基于 **DeepSeek** 的浏览器 Agent 初版：向它描述目标（操作类：登录、搜索、填表、抓取；总结类：提炼页面要点），它会**跨页面**自主观察页面 → 决策 → 执行，直到完成。

## 功能特性

- **页面理解**：把当前页面抽象成"可交互元素快照 + 正文摘要"喂给大模型。读的是**浏览器当前渲染的 DOM**（不是服务端源码），所以动态构建的元素（React/Vue 渲染、CSS-module hashed class 等）都能读到；纯 JS 用 `addEventListener` 绑的 div/span 按钮（没有 role/onclick 等属性）也能识别——靠扫描样式表里 `cursor:pointer` 的手型选择器 + role/aria 属性，快照照样列得出、点得到。
- **操作目标**：点击、输入、下拉选择、滚动、按键、跳转页面，逐页完成任务。
- **总结摘要**：通过 `read` 动作读取正文，输出结构化中文总结。
- **持续对话模式**：不是"一次任务就结束"，而是聊天式多轮对话——Agent 完成一条指令后用 `finish` 给出答复并**等待你的下一条指令**；对话记录跨轮保留，可以追问（"把刚才的总结存成文件"），也可以在它运行中直接发新指令打断它。Agent 自开的标签在本轮完成/失败时**自动清理**（直接删除它创建的 "PageAgent N" 标签分组，一步清空全部自开标签；你给的标签 @MAIN/@U 永不关闭）。
- **多会话（最多 5 个）**：可以同时跑最多 5 个互不干扰的会话，各自独立的聊天消息列表，通过**顶部会话栏**（状态栏上方一排"会话N"胶囊 + 颜色状态点）点击切换。每个会话的 Agent 自开标签自动归入**带序号的标签分组**（`PageAgent 1`、`PageAgent 2`…），开页面关页面**互不影响**——关掉一个会话的标签页不影响其他会话继续运行；各会话的等待确认/回复各自归属，不会串台。底部按钮改为**「清空本会话」**（只关当前会话的 Agent 标签、清空其记录，会话保留）；新建会话走顶部会话栏的 **＋ 新建**（满 5 个时禁用），删除会话点胶囊上的 **×**。
- **结果下载**：要求"总结成文件/导出"时，Agent 用 `save_file` 动作把结果写成文件直接下载到本地（md/txt/json/csv/html 等）。
- **书签读写**：Agent 可以读取 Chrome 书签（`bookmarks_read`，可只读某个文件夹）和写入书签（`bookmarks_write`，指定文件夹不存在时自动创建），支持"查一下我收藏了哪些 AI 工具""把当前页加入收藏"这类指令。写入时一律收藏该网站的**根 URL**（协议+域名，自动去掉路径/查询），标题描述的是**整个网站**的作用，不是某个局部页面的作用。
- **书签当网站工具索引**：对话开始和每条新指令时，Agent 会把书签（"文件夹/标题 — 网址"，标题即用途）载入上下文常驻。之后收到"去 Claude 问个问题""打开我的网盘"这类指令，它能凭标题直接匹配网址、用 `open_tab` 快速打开，不用盲目网页搜索；书签较多（>200 条）时索引只列前 200，超出的用 `bookmark_find` 按关键词精确查找。
- **任务复盘收藏**：每条任务完成后，Agent 会复盘本次任务**实际访问过**的网站（只看本轮动作打开的网址 + 每步快照的当前页面，不扫标签列表和正文里的杂散链接；**按域名归并**——同一域名访问再多页也只算一个网站，不会把"一页结果、一页笔记"数成两个；`www.xx.com` 与 `xx.com` 等二级域名前缀不同就算不同网站），用大模型筛出对以后有用的工具/平台/资料站，直接写入书签根目录（不建文件夹，避免越攒越乱），标题格式为"网站名 | 作用 | 使用技巧"（如 `小红书 | 用户内容查询 | 直接点击第一条结果、别点推荐流更准`；已收藏过的网站则把本次新总结的使用技巧合并进既有书签标题，同样三段式，越用越精准），让书签索引越用越丰富。收藏的 URL 一律是**网站根地址**（协议+域名，不带路径），标题只描述**网站整体**的作用，不针对访问到的某个局部页面；概括"作用"时按**实际用到的功能**写，**过滤掉网站自己的广告语/营销文案**（如"全球领先""一站式平台""引领未来"这类自我宣传），不照抄。
- **网站操作技巧库（技巧总结）**：每条任务完成后的复盘阶段，Agent 会把本次任务中**反复失败了好几次、或绕了弯路多点了很多次**的操作，总结成"该网站的操作技巧"（只记录**域名**，不记录路径），存到本地；已收藏过该站点技巧时，会带上既有技巧做**冲突去重合并**，持续全量优化。此后每次操作该网站时，Agent 会先加载该站的技巧注入上下文（消息列表显示「加载 x 个相关技巧 XXms」），优先遵循这些历史经验，少走弯路。面板底部「技巧」按钮可查看 / 编辑 / 删除各网站的技巧记录。
- **卡住转人工**（分三种模式）：遇到验证码、登录墙、人机验证等无法自动完成的情况，Agent 用 `ask_user`（`mode:page`）暂停并请你**在页面上**手动操作（自动把相关标签切到前台），你操作完后点气泡里的 **"我已操作完成，继续"** 按钮，它接着往下做；需要你提供信息（账号、手机号、补充要求等）时，Agent 用 `ask_user`（`mode:reply`）请你**在对话里直接回复**——此时不显示"继续"按钮，直接在下方输入框打字即可。连续操作失败也会自动转人工求助；若 Agent 反复执行同一动作/反复失败、原地打转毫无进展（累计到阈值），会自动升级成**请你手把手演示**（教我模式），不再闷头重试。
- **教我模式（手把手演示学习）**：当你对 Agent 说「我教你 / 我演示 / 你看我怎么操作」这类话（或它卡住反复失败、重复同一操作仍无进展时，主动请求 `ask_user mode:teach`）时，它会暂停操作，弹出琥珀色「请你演示操作」教卡，并**实时记录你在页面上的每一步操作**（点击 / 输入 / 下拉选择 / 回车提交，教卡显示「已记录 N 步」，只记录真实用户操作；若你操作的元素是**悬浮才出现的**——如列表行悬浮才显示的编辑/删除按钮、下拉菜单——悬浮这一步也会被自动记录为步骤，回放时先悬浮再操作）；录制**覆盖任务下的所有标签页**——不只当前标签，你在演示中切到 / 新开的标签也会自动纳入并继续录制，跨页、跨站演示都不会断。你操作完点「我操作完了」，Agent 先用气泡**复述**你教的步骤，再弹出确认卡——你点**「没问题，按我教的继续」**按钮它就照做；有出入或问题直接在输入框纠正，它会**重新理解、修正后再来找你确认**（复述-确认-再确认循环，直到你点「没问题」、或回复「不教了/算了」「你先去做吧/你自己来」让它自己接着做为止）；你明确说「重新演示」则重开一个新的演示。教完并**经你确认复述无误后**的操作，会**沉淀成该网站的操作技巧**存入技巧库（只记动作流程，**不含输入的具体值**——账号、密码等不会写进去；仅当前这轮会用到你演示时输入的内容），以后操作同一网站时自动加载复用。
- **拟人操作**：输入逐字（15–45ms/字）、点击随机间隔 0.5–2s、动作间随机停顿 0.2–0.8s（`wait` 动作，日志显示「假装人类 · Nms」），模拟真人浏览节奏，降低被风控误判的概率；但**连续 wait 而没有任何实际动作、页面也没变化时，会识别为无进展空转并自动停止停顿**——第二次起不再空等，直接把"禁止再 wait、去做实际动作或 finish"写回上下文，推动 Agent 继续（若等待后又重复执行同一个动作也会提示），不再浪费时间原地踏步。
- **友好活动轨迹**：会话区只显示给使用者看的极简动作痕迹（如「正在浏览 小红书 · 80ms」「打开 www.xiaohongshu.com/… · 23ms」「点击 · 50ms」「输入 · 40ms」，只报做了什么 + 耗时；URL 去掉协议头、中间过长用省略号，不列标签/输入值等细节），不显示 LLM 重试、快照失败、原始 JSON 等技术噪音；技术细节可到扩展的 Service Worker 控制台查看。
- **充分使用大上下文**：默认按 DeepSeek V4 的 1M token 上下文窗口装历史——尾部历史从最新往前一直装到放不下为止（默认窗口、压缩阈值都可在设置里调），不再固定只发最近 24 条。
- **上下文自动压缩**：当要发送的内容达到上下文窗口的 70%（默认，可调）时，自动把中间历史压缩成一份紧凑摘要再继续，保留「你的原始目标 + 最近两步原文」，过程中 `read` 页面内容这类最占上下文的「动作调用+结果」成对删除；摘要交给大模型总结成「已完成进展 / 踩过的坑 / 用户补充的注意点」三部分，输入过长时分块链式合并。压缩后上下文大幅释放，长对话可持续很多轮。
- **图标角标**：工具栏图标右下角实时显示状态——蓝色=有会话在运行/加载中（旋转动画 + **运行中的会话数**，如 `2-` `2\` `2|` `2/` 轮转）、橙色闪烁 `!`=有会话需要你手动操作、无角标=空闲。
- **多标签编排**：Agent 会自主开后台标签（不抢焦点、不影响你浏览），自开标签自动归入**本会话编号**的 "PageAgent N" 标签分组统一管理（N 为该会话序号，各会话分组独立）；你交给它的那个标签（@MAIN）不入组。点击页面里"新开页面"的链接（`target="_blank"`）也不会抢你的焦点——会改为**后台打开**并纳入 Agent 自开标签（@T 系，本轮结束随分组一起清理，不当作你的页面）；个别用 JS `window.open` 新开页面的网站，后台会兜底把焦点还给你。
- **全标签感知**：Agent 能用 `list_tabs` 读取浏览器里**所有**已打开的标签（标题+网址，标记当前前台选中的那个、已在任务里的和无法操作的受限页），回答"我现在正在看哪个页面""我开了哪些标签"这类问题；也能用 `use_tab` 把你已打开的任意标签**纳入任务**继续操作（如"在我已经打开的某某标签里做 XX"），同样不抢焦点、不切浏览器前台，不打扰你浏览。
- **跨页面运行**：`open_tab` / `navigate` 后自动等待对应标签就绪并继续同一任务（历史上下文跨标签保留）。
- **可配置大模型**：默认 DeepSeek V4 Flash（`deepseek-v4-flash`，1M 上下文），接口为 OpenAI 兼容格式，可换任意兼容端点（OpenAI、代理、本地 Ollama 网关等）。注：`deepseek-chat`/`deepseek-reasoner` 是 V3/R1 时代的旧别名，已于 2026-07-24 退役，请改用 V4 新 ID。

## 安装

1. 打开 `chrome://extensions`，开启右上角 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择本目录。
3. 点击工具栏中的扩展图标（或右键扩展 → 打开侧边栏）打开 **PageAgent** 侧边栏。

## 配置

在侧边栏点 **设置**：

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| API Key | DeepSeek API Key（[申请](https://platform.deepseek.com)） | 空 |
| Base URL | OpenAI 兼容接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-v4-flash`（V4 Flash，推荐）或 `deepseek-v4-pro` | `deepseek-v4-flash` |
| 温度 | 0–2 | 0.2 |
| 最大步数 | Agent 最多执行的决策步数 | 25 |
| 上下文窗口 | 按 token 估算的输入上下文上限 | 1000000（DeepSeek V4 为 1M） |
| 压缩阈值 | 上下文使用到该比例时自动压缩历史 | 70 |
| 搜索模板 | 任务与当前页无关时，Agent 用它开搜索页 | `https://www.bing.com/search?q=` |

## 使用

1. 切换到你想让 Agent 操作的标签页（Agent 运行在该标签页内，作为对话的 @MAIN）。
2. 在侧边栏底部输入框下达指令，回车发送，例如：
   - `在百度搜索"DeepSeek"，打开第一条结果，总结该页面要点`
   - `在本页完成登录（用户名 xxx，密码 yyy），然后进入"订单"页，列出第一页的订单号`
   - `总结当前页面的主要内容`
3. Agent 会在聊天区逐步显示友好活动轨迹（灰字，如「打开了 xxx · 20ms」「点击了「搜索」· 50ms」），完成后以气泡给出答复并**回到就绪状态**，你可以继续下达下一条指令（如 `把刚才的总结保存成文件`）。
4. 运行中可 **■ 停止**（对话不结束，可继续发新指令；停止后仍会照常做复盘——把本轮访问过的网站沉淀成书签、把反复失败/绕弯路站点的操作沉淀成技巧）；想清空当前会话用 **清空本会话**（只关本会话 Agent 自开的标签并清空记录，会话保留，可继续发新指令；想彻底开一个新会话，点顶部会话栏的 **＋ 新建**）。

> 说明：
> - 首条指令所在的标签被固定为该会话的 @MAIN；后续指令继续在 @MAIN 和你已纳入的标签（@U 系）上工作。要换一个页面工作，请点顶部会话栏 **＋ 新建** 开一个新会话后再发指令，或直接让 Agent `open_tab` / `switch_tab` / `use_tab`。
> - **顶部会话栏**：状态栏上方一排"会话N"胶囊，圆点颜色表示该会话状态（灰=空闲、蓝=运行中、橙=需你手动操作/等我教、绿=等待确认）。点胶囊切换会话——各会话的消息列表、标签分组、运行状态互不干扰；点胶囊上的 **×** 删除会话（运行中的会先停止并复盘，只关该会话的 Agent 自开标签，你的 @MAIN/@U 标签与其他会话不受影响）；末尾 **＋ 新建** 开新会话（最多 5 个，满员时禁用）。
> - 在 Agent 运行中直接发送新指令/补充说明，会**打断**当前操作并立即重视采纳——补充说明可能是纠正你当前做法的指导（它照此调整、继续推进原目标），也可能就是明确改变目标（它据此切换）；它**不会一收到就盲目放弃原始目标**。
> - 需要登录的站点，Agent 会在当前已登录的浏览器会话中操作，不需要额外凭证。
> - 面板底部「技巧」按钮可查看 / 编辑 / 删除各网站沉淀的操作技巧；Agent 操作这些网站时会自动加载并优先遵循（消息列表显示「加载 x 个相关技巧 XXms」）。

## 架构

```
panel.html/js/css  侧边栏 UI（顶部会话栏、聊天消息流、设置、发送/停止/清空本会话）
       │  chrome.runtime 消息
background.js      Service Worker：Agent 循环（多会话）+ DeepSeek 调用 + 状态持久化
       │  tabs.sendMessage / tabs.update / scripting 注入
content.js         页面快照（可交互元素 + 正文摘要）+ 动作执行（click/type/…）
```

**Agent 循环**：`GET_SNAPSHOT`（当前操作标签）→ 拼接快照消息（含标签页列表 + 书签索引 + 原始目标 + **本站操作技巧**（当前站点历史沉淀的技巧，首次进入该站时消息列表显示「加载 x 个相关技巧 XXms」）+ 尾部历史窗口；上下文使用达 70% 阈值时先自动压缩中间历史为摘要）→ 调 DeepSeek（`response_format: json_object`）→ 解析动作 → 执行 → 重复。`finish` 或失败后回到 `idle`（等待下一条指令），**不结束对话**；`maxSteps` 按"每轮指令"重置。

**复盘**：`finish` 时并行做两件事——① 书签复盘：把本轮实际访问过的网站筛出有用的写入书签（新网址收藏 / 已收藏的合并改进标题，一律存网站根 URL）；② 技巧复盘：统计本轮各站点的动作数/失败数，对有"反复失败（≥2 次）或绕弯路（动作 ≥4 次）"信号的站点，用大模型总结成站点技巧，带上该站既有技巧做冲突去重合并后存到本地（只记域名）。

**多标签编排**：
- `@MAIN`：使用者点"开始"时所在的标签，属使用者，**不入分组**。
- `@T1/@T2/...`：Agent 用 `chrome.tabs.create({active:false})` 自开的后台标签，**不抢焦点**；首个自开标签用 `chrome.tabs.group` 新建分组并命名 "PageAgent N"（N 为本会话编号，默认折叠、灰色），后续自开标签加入**本会话**的分组。
- `@U1/@U2/...`：Agent 用 `list_tabs` 看到浏览器里已打开的标签后，用 `use_tab` 把你已有的标签纳入任务继续操作（同样不切浏览器前台）。
- 动作：`open_tab`（开后台标签+入组）、`switch_tab`（切换 Agent 关注的操作标签，不切浏览器前台）、`list_tabs`（列出浏览器全部标签、标记当前选中）、`use_tab`（把使用者已有标签纳入任务）、`close_tab`（关自开标签，@MAIN/@U 等使用者标签不可关，Agent 自开上限 8 个）。
- 每轮结束（`finish`/失败）直接删除**本会话**的 "PageAgent N" 标签分组（组内即 Agent 自开 @T 标签，删组一步清空；分组外的 @T 逐个兜底关闭）；使用者的标签（@MAIN/@U）永不自动关闭，"清空本会话"清理同样只删本会话分组、只清 @T 系，**不影响其他会话的标签分组**。
- 访问新页面 Agent 优先 `open_tab`，仅在需沿用当前标签登录会话时才 `navigate`。

**跨页面/跨标签恢复**：`open_tab`/`navigate` 后任务置为 `awaiting_nav`（记录等待的 `waitTabId`）；对应标签 content script 加载后广播 `AGENT_READY`（`tabs.onUpdated` 兜底）恢复循环。任务状态持久化到 `chrome.storage.session`，应对 MV3 service worker 被回收。心跳 alarm 每分钟唤醒并检测加载超时（120s）与循环停滞自愈。

**动作集**：标签：`open_tab` / `search` / `switch_tab` / `list_tabs`（读浏览器全部标签）/ `use_tab`（纳入使用者已有标签）/ `close_tab`；页面：`click` / `hover`（悬浮元素以显示"悬浮才出现"的操作项，如行内编辑/删除按钮、下拉菜单）/ `type` / `select` / `scroll` / `read` / `wait` / `keypress` / `navigate`；结果：`save_file`（保存为文件下载）；书签：`bookmarks_read`（读 Chrome 书签）/ `bookmarks_write`（写入书签，自动收藏网站根 URL、标题描述网站整体作用，同一网站已收藏时合并改进其标题并规整 URL 为根）/ `bookmark_find`（按关键词查找书签）；求助：`ask_user`（`mode:page` 请你手动操作页面、`mode:reply` 请你直接在对话里回复、`mode:teach` 请你手把手演示操作来学习、`mode:confirm` 请你点按钮确认复述）；消息：`say`（在对话区说一句话、不打断流程，如复述学到的步骤）；结束：`finish`。

> Agent 会**先判题**：`@MAIN` 当前页与任务无关时（例如"搜索 DeepSeek 资讯并总结"），不会在当前页瞎操作，而是用 `search`（按上面"搜索模板"后台开搜索页）或 `open_tab`（已知网址/网站）新开标签处理；只有任务确实发生在当前页时才在当前页操作。

> `save_file` 需要 `downloads` 权限；文件下载到浏览器默认下载目录（`saveAs:false`）。文件名会做安全清洗（去除路径分隔符等），并支持 md/txt/json/csv/html/yaml 等扩展名自动识别 MIME。

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、side panel、content script 注入 |
| `background.js` | Agent 循环（多会话）、LLM 调用、会话状态、跨页恢复、广播 |
| `content.js` | 页面快照生成、动作执行、AGENT_READY 上报 |
| `panel.html/css/js` | 侧边栏 UI |

## 已知限制（初版，待优化）

- **后台标签可能被 Chrome 丢弃**：内存压力下 Chrome 可能 discard 后台标签，被丢弃后无法操作，任务会等待直至超时。长任务建议关掉不用的标签。
- **受限页面**：content script 无法注入 `chrome://`、Chrome 商店等受限页面。Agent 检测到当前标签是受限页面时会自动跳过（直接 `open_tab` 另开任务相关的网页），不会反复失败空转。
- **上下文成本**：每步携带快照，LLM 输入为 system + 书签索引 + 压缩摘要（有压缩时）+ 原始目标 + 从最新往前尽量装满窗口的历史；上下文用满的代价由 DeepSeek 的自动前缀缓存摊薄（长前缀命中缓存，每步只付增量）。超大页面靠 `read` 按需取全文。
- **动态页面**：动作定位优先用快照时的 live 元素引用（`ref`→元素），元素被重渲染替换后才回退到 CSS 选择器（id/testid/位置，**不用 class**——动态 app 的类名常带随机后缀不稳定）；快照每次决策都重新扫描，动态新增的可点元素（含手型样式的 div/span 按钮）会进 ref 列表。
- **LLM 限流/费用**：DeepSeek 需要有效 Key，注意账户余额与频率限制。
- **自开标签自动清理**：Agent 自开的标签在本轮任务完成/失败时自动清理——直接删除它创建的 "PageAgent N" 标签分组（组内即 @T 标签，删组一步清空，分组外的逐个兜底关闭）；你打开的标签（@MAIN/@U）永不被自动关闭。"清空本会话"清理同样只删本会话分组、只清 @T 系，不影响其他会话。注意：若你手动把**自己的标签**拖进 PageAgent 分组，删除分组时会一并关闭，所以请不要把个人标签放进该组。
